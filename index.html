Add a new store

Connect a new Shopify store by setting up a webhook in ParcelPanel. Requires the Professional plan or higher for webhook access.

1
Open ParcelPanel in your new store's Shopify admin
2
Go to Integrations → Webhooks → Add webhook
3
Set event to shipment_status / any_update
4
Paste this URL:
https://frxyfmfjtadyxhfogdvt.supabase.co/functions/v1/webhook
5
Click Save — the new store appears here automatically after the first shipment update.
