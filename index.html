Connect a new Shopify store via ParcelPanel. Requires the Professional plan for webhook access.

1
Open ParcelPanel in your new store's Shopify admin
2
Go to Integrations → Webhooks → Add webhook
3
Set event to shipment_status / any_update
4
Paste this URL:
https://frxyfmfjtadyxhfogdvt.supabase.co/functions/v1/webhook
5
Click Save — the store appears automatically after the first update.

This will permanently delete all shipment data for the selected store. This cannot be undone.
